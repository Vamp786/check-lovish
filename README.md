# Muktsar Visual — Creative Digital Marketing & Content Production Website

Official promotional website for **Muktsar Visual**, a creative digital marketing and content production studio.

## Project Structure

```text
muktsar-visual/
├── index.html        # Main semantic HTML5 structure
├── css/
│   └── style.css     # Custom editorial animations, navigation & camera cursor styles
├── js/
│   └── script.js     # Scroll-spy navigation, camera viewfinder cursor, modals & form logic
└── README.md         # Project documentation & GitHub Pages setup guide
```

## Core Services Highlighted
1. **Content Creation** — High-quality photos, videos, reels, and promotional visuals.
2. **Creator Management** — Connecting brands with vetted creators for collaborations.
3. **Advertisement Creation** — Engaging commercial advertisements for brands.
4. **Paid Ads & Campaign Management** — Targeted Instagram & Facebook ad campaigns.
5. **Brand Promotion** — Full-spectrum brand awareness, engagement, and visibility.

## How to Deploy on GitHub Pages
1. Upload the **contents** of the `muktsar-visual/` folder (`index.html`, `css/`, `js/`, `README.md`) directly to the root of your GitHub repository.
2. Open your repository **Settings → Pages**.
3. Under **Build and deployment**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, and click **Save**.
